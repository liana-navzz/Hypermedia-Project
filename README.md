-------- Project analysis, User profile --------

The user profile chosen for this project (Curriculum Vitae) is a fictional character from the TV series The Mentalist. His name is Patrick Jane and is the main caharacter of the series. I have chosen him because he has a very appropiate profile for a CV, having lots of work experience and abilities.

-------- Project analysis, Information architecture --------

I split the page into a header and a body, and the body into three zones.

HEADER: A full-width dark blue band holds who Patrick is. The photo sits on the left. Beside it are the name and job title and the three contact lines, each with its own icon. This is the first thing the reader sees.

-BODY PARTS-

SUMMARY: Directly below the band, a short paragraph with a blue bar on its left gives the overall profile before any detail.

LEFT COLUMN: This holds the compact, quick-scan material: work skills, certifications, interests and languages. Each has an icon, an uppercase title and a thin rule. Languages show five dots for level instead of plain text.

RIGHT COLUMN:  This is the main content: work experience, in reverse chronological order. Each job has a dot beside its date, then the role, the employer in bronze, and a description. Thin lines separate the jobs.

-------- Project analysis, Visual design --------

I built the design around contrast and restraint, so it feels professional rather than decorative.

PALETTE: I used a deep navy and a warm beige as the two main colors. Navy carries the header band, titles, bullets and the dots. Beige is the page background, which feels softer than pure white. A tan color serves as a thin accent line under the header and as the divider color, and a bronze marks employer names. Body text is a dark blue-gray, never pure black, and all text keeps strong contrast against its background.

HEADER: A full-width navy band anchors the page. Patrick Jane's photo stays on the left. The name is large in beige, the title is in light tan.

TYPOGRAPHY: I kept the original serif, Libre Baskerville, so the content is unchanged.

ICONS AND DETAILS: Simple outline icons with the same stroke weight appear beside the contact lines and section titles. Dots mark dates and language levels. Thin rules and a faint column divider organize the content without heavy boxes.

SPACING: I tightened and unified the spacing so everything fits on one page without crowding, with a clear rhythm between sections, keeping the shape of a professional CV.
